# Writing

These rules apply to all text: replies, docs, code comments, AI prompts, issue and PR text, and commit messages.

- No em dash (`—`), en dash (`–`), semicolon or emoji. End the sentence, or use a comma, colon or parentheses. Semicolons that are part of code or shell syntax are fine.
- Use the real names from the code and tools, not metaphors or paraphrases. builder, reviewer and resolver together are the workers. Keep git and GitHub terms such as worktree, clone, fetch and push as they are.
- Do not string command options and paths into a sentence. "Fetch, then make a new worktree. Remove the worktree when the work is done." is the right density. Give options and paths only when asked.
- This repository is public. Docs, code comments, AI prompts, issues, PRs and commit messages do not name the user's other repositories or describe the work in them. Use exomecha's own terms. Replies to the user may name them.
